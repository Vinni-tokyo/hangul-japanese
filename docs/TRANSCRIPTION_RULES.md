# 일본어 한글 표기 규칙 초안

v0.1 학습 자료에서 일본어의 소리를 현대 한글로 읽기 쉽게 나타내는 프로젝트 내부 기준이다. 뜻과 문법은 원래 일본어 표현을 유지한다. 일본어 독음이 필요할 때는 원문의 가나를 함께 확인한다. 학습자 안내는 일본어 문구 `ハングルは日本語の音を近い音で表しています。`를 사용한다.

## 기본 대응

기본 자모 카드는 기획서의 표기를 기준으로 한다. 비슷하게 들리는 가나가 있는 경우 `phoneticMatch: "approximate"`를 사용한다. ㅓ, ㅕ, ㅡ의 학습용 일본어 칸은 `null`로 두고 `phoneticMatch: "none"`으로 표시한다. 이 경우 한국어 예시와 일본어 설명을 넣는다.

조합 화면의 대응은 `src/data/combinationKana.json`에서 한글 음절을 키로 조회한다. 가나 값은 히라가나로 통일한다. 예를 들어 `가 → が`, `카 → か`, `차 → ちゃ`를 보여 준다. 같은 가나가 상황에 따라 다르게 들릴 수 있으므로 화면의 대응은 연습용 근삿값으로 사용한다. 표에 등록되지 않은 음절은 가나 칸을 비워 둔다.

일상 표현은 단어의 문맥을 반영해 편집한다. 조합 화면은 기본 자음과 기본 모음으로 만들 수 있는 음절만 대상으로 한다. 일상 표현에 등장하는 `네`, `테`, `와` 등은 현대 한글의 다른 모음을 사용한다.

## v0.1에서 쓰는 표기

| 항목 | 처리 방식 | 예시 |
| --- | --- | --- |
| 장음 | 초급 한글 표기에서는 모음 길이 표시를 생략한다. 가나에서는 う, い, ー 등 원래 표기를 보존한다. | おはよう → 오하요, カード → 카도, とうきょう → 토쿄 |
| 촉음 っ | v0.1 예시의 t 계열 앞에서는 앞 음절의 ㅅ 받침으로 표시한다. 다른 자음 앞의 표기 규칙은 후속 검토 대상으로 둔다. | チケット → 치켓토, とっても → 톳테모 |
| 요음 | 작은 ゃ・ゅ・ょ가 들어가는 가나는 문맥에 맞는 한글 음절 하나로 적는다. | だいじょうぶ → 다이죠부, しょうしょう → 쇼쇼, おちゃ → 오차 |
| ん | v0.1 예시에서는 앞 음절의 ㄴ 받침으로 적는다. 주변 소리에 따른 ん의 실제 발음 변화는 Level 6에서 설명한다. | ラーメン → 라멘, おんがく → 온가쿠 |
| つ | 단어 안에서 츠로 근사하는 사례를 제공한다. 조합 화면에서는 ㅡ를 쓰는 음절에 가나를 표시하지 않는다. | おつかれさまです → 오츠카레사마데스 |
| ざ・ず・ふ | 표본의 ざ는 자로 근사한다. ず와 ふ의 표기와 소리 차이는 Level 6에서 검토한다. | ざいりょう → 자이료 |
| 조사 | 실제 읽는 소리에 맞추어 は는 와, を는 오로 적는다. 예문의 가나 칸에는 조사 원문을 유지한다. | わたしは → 와타시와, おちゃを → 오차오 |
| 피치 악센트 | 문장 데이터에서 악센트 표지를 생략한다. | Level 6에서 소리 차이를 다룬다. |

가나에 적힌 `えい`가 장음으로 읽히는 용례에도 장음 규칙을 적용한다. 예를 들어 일상 표현의 `えいが`는 `에가`로 표시한다. `いいね`의 긴 이 소리도 `이네`처럼 음절 하나로 표기한다. Level 1의 지정 예시 `がくせい → 가쿠세이`는 기획서 표기를 유지한다.

## 원문과 한국어 대응 표현

가나 칸의 외래어는 가타카나로 유지한다. 일반적으로 가나로 쓰는 표현은 혼용 표기 칸에도 그대로 실을 수 있다. 첫 화면 예시의 `ありがとうございます / 有難うございます`처럼 기획서에서 두 형태를 제시한 항목은 해당 형태를 보존한다.

한국어 대응 표현은 같은 상황에서 자연스럽게 쓸 수 있는 문구를 담는다. 예를 들어 식사 전의 `いただきます`는 `잘 먹겠습니다`로 제시한다.
