# Hangul Japanese Project — MVP 개발 기획 및 작업 지시서

## 1. 프로젝트 개요

- 프로젝트명: Hangul Japanese
- 일본어 서비스명: 日本語で学ぶハングル
- GitHub Repository: https://github.com/Vinni-tokyo/hangul-japanese
- 프로젝트 유형: 공개 오픈소스 프로젝트
- 주요 대상: 한글을 모르는 일반 일본인
- 기본 서비스 언어: 일본어
- 서비스 형태: 모바일 및 PC에서 사용할 수 있는 반응형 웹 플랫폼

### 프로젝트 슬로건

**日本語に、新しい文字の選択肢を。**

일본어에 새로운 문자 선택지를.

**日本語でハングルを学ぼう！**

일본어로 한글을 배우자!

## 2. 프로젝트 목적

이 프로젝트의 핵심 목적은 일본인에게 한국어를 가르치는 것이 아니라, 한글이라는 문자 체계를 가르치는 것이다.

일본인이 이미 알고 있는 일본어의 소리와 의미를 활용하여 한글을 익히도록 한다.

일본어라는 언어는 유지하고, 이를 표현하는 새로운 문자 체계로 한글을 활용한다.

기존의 한국어 교육과 다음과 같은 차이가 있다.

| 구분 | 기존 한국어 교육 | Hangul Japanese |
|---|---|---|
| 학습 대상 | 한국어 | 한글 문자 |
| 학습 재료 | 한국어 단어와 문장 | 익숙한 일본어 단어와 문장 |
| 문법 학습 | 필요 | 불필요 |
| 어휘 암기 | 필요 | 필수 아님 |
| 주요 목표 | 한국어 의사소통 | 한글 읽기와 쓰기 |

## 3. 핵심 설계 원칙

1. 일본인이 이미 알고 있는 일본어를 학습 재료로 사용한다.
2. 한글 문자 학습을 최우선 목표로 한다.
3. 한글의 전통적인 기본 자음 및 모음 학습 순서를 유지한다.
4. 모든 일본어 학습 콘텐츠는 기본적으로 4개의 표현 체계를 제공한다.
5. 초기 버전은 현대 한글 문자만 사용한다.
6. 일본어와 한글의 발음 차이는 별도로 설명한다.
7. 옛한글 및 확장 한글은 향후 연구 과제로 분리한다.
8. 한국어 학습을 강요하지 않는다.
9. 일본인이 부담 없이 접근할 수 있도록 모든 주요 UI와 학습 설명은 일본어로 제공한다.

## 4. 학습 데이터의 기본 구조

모든 일본어 단어와 문장은 다음 순서로 표현한다.

| 순서 | 표현 체계 | 예시 |
|---|---|---|
| 1 | 한글 일본어 (ハングル表記の日本語) | 아리가토고자이마스 |
| 2 | 가나 일본어 (かな表記) | ありがとうございます |
| 3 | 한자 혼용 일본어 (漢字かな交じり文) | 有難うございます |
| 4 | 대응 한국어 (韓国語表現) | 감사합니다 |

첫 번째 표현인 한글 일본어가 핵심 학습 대상이다.

가나 일본어는 한글의 소리를 확인하는 역할을 한다.

한자 혼용 일본어는 익숙한 일본어 표기와 의미를 확인하는 역할을 한다.

대응 한국어는 동일한 의미를 가진 실제 한국어 표현을 참고하기 위한 것이다.

가나 표기에서 외래어는 가타카나를 유지한다.

자연스러운 일본어에서 한자를 사용하지 않는 표현은 억지로 한자화하지 않는다.

## 5. 학습 커리큘럼

### Level 1. 기본 자음

基本子音を学ぼう

반드시 다음 순서를 유지한다.

**가나다라마바사아자차카타파하**

|---|---|---|---|---|---|
| ㄱ | 가 | 가쿠세이 | がくせい | 学生 | 학생 |
| ㄴ | 나 | 나마에 | なまえ | 名前 | 이름 |
| ㄷ | 다 | 다이죠부 | だいじょうぶ | 大丈夫 | 괜찮아 |
| ㄹ | 라 | 라멘 | ラーメン | ラーメン | 라면 |
| ㅁ | 마 | 마타네 | またね | またね | 또 봐 |
| ㅂ | 바 | 바쇼 | ばしょ | 場所 | 장소 |
| ㅅ | 사 | 사쿠라 | さくら | 桜 | 벚꽃 |
| ㅇ | 아 | 아리가토 | ありがとう | ありがとう | 고마워 |
| ㅈ | 자 | 자이료 | ざいりょう | 材料 | 재료 |
| ㅊ | 차 | 오차 | おちゃ | お茶 | 차 |
| ㅋ | 카 | 카사 | かさ | 傘 | 우산 |
| ㅌ | 타 | 타마고 | たまご | 卵 | 달걀 |
| ㅍ | 파 | 파스타 | パスタ | パスタ | 파스타 |
| ㅎ | 하 | 하나 | はな | 花 | 꽃 |

학습 대상 문자는 예시 단어 안에서 강조하여 표시한다.

예: 가쿠세이에서 '가'를 강조한다.

각 자음에 대해 자음과 모음이 결합되는 구조도 함께 보여준다.

예: ㄱ + ㅏ = 가

### Level 2. 기본 모음

基本母音を学ぼう

반드시 다음 순서를 유지한다.

**아야어여오요우유으이**

| 모음 | 기본 문자 | 한글 일본어 | 가나 | 일본어 | 한국어 |
|---|---|---|---|---|---|
| ㅏ | 아 | 아시타 | あした | 明日 | 내일 |
| ㅑ | 야 | 야스미 | やすみ | 休み | 휴식 |
| ㅓ | 어 | — | 対応する音なし | — | 어디 |
| ㅕ | 여 | — | 対応する音なし | — | 여기 |
| ㅗ | 오 | 오하요 | おはよう | おはよう | 좋은 아침 |
| ㅛ | 요 | 요로시쿠 | よろしく | よろしく | 잘 부탁해 |
| ㅜ | 우 | 우미 | うみ | 海 | 바다 |
| ㅠ | 유 | 유메 | ゆめ | 夢 | 꿈 |
| ㅡ | 으 | — | 正確に対応する音なし | — | 으뜸 |
| ㅣ | 이 | 이마 | いま | 今 | 지금 |

일본어에 정확한 대응음이 없는 한글 모음은 별도의 설명과 한국어 예시로 학습할 수 있도록 한다.

### Level 3. 문자 조합

子音と母音を組み合わせよう

기본 자음 14개와 기본 모음 10개를 조합하는 인터랙티브 학습 기능을 구현한다.

- 자음 선택
- 모음 선택
- 조합된 한글 문자 실시간 표시
- 총 140가지 기본 조합 지원
- Unicode 한글 음절 조합 원리 활용

예시:

ㄱ + ㅏ = 가

ㄴ + ㅏ = 나

ㅁ + ㅗ = 모

ㅎ + ㅏ = 하

일본어 대응음이 존재하는 경우 가나를 함께 표시한다.

대응음이 없는 경우 임의의 가나를 생성하지 않는다.

### Level 4. 쌍자음과 복합 모음

- 쌍자음 5개
- 복합 모음 11개
- 일본어 대응 가능 여부
- 한국어 보충 예시

### Level 5. 받침

パッチムを学ぼう

- 받침의 개념
- 자음, 모음, 받침의 조합
- 27개의 받침 형태
- 일본어의 ん과 っ를 활용한 입문 예시
- 일본어로 표현하기 어려운 받침은 한국어 예시로 보충

### Level 6. 일본어 특수 소리

日本語とハングルの音の違い

다음과 같은 일본어 소리의 특징을 설명한다.

- つ
- ざ、ず
- ふ
- ん
- 長音
- 促音
- 拗音
- ピッチアクセント

현대 한글을 사용하여 근사적으로 표현하되, 완전히 동일한 발음이 아니라는 사실을 명확히 안내한다.

일본어 장음 및 촉음에 대한 프로젝트 자체 표기 규칙은 별도의 문서로 관리한다.

### Level 7. 일본어 일상 표현

ハングルで日本語を読もう

일상 표현을 주제별로 제공한다.

- 인사
- 자기소개
- 친구와 대화
- 회사 생활
- 카페와 식당
- 쇼핑
- 교통
- 여행
- 취미

장기적으로 200개 이상의 일본어 일상 표현을 제공한다.

표현 개수뿐 아니라 한글 자모 및 받침의 학습 커버리지를 고려하여 데이터를 선정한다.

200개는 초기 콘텐츠 설계 목표이며 검증된 학습량은 아니다.

## 7. 학습 카드 UI

학습 카드의 표시 순서는 다음과 같다.

1. 학습 대상 한글 문자
2. 자음과 모음의 조합
3. 한글로 표현한 일본어 단어
4. 가나 표기
5. 한자 혼용 일본어 표기
6. 대응 한국어 표현
7. 이전 및 다음 문자 이동

한글 문자를 가장 크고 눈에 띄게 표시한다.

가나 및 일본어 표현은 학습 보조 정보로 표시한다.

정답 확인, 가나 숨기기 등의 기능을 제공하여 스스로 한글을 읽어볼 수 있게 한다.

## 8. 퀴즈 기능

퀴즈의 목적은 일본어 능력을 측정하는 것이 아니라 한글 문자 인식 능력을 측정하는 것이다.

### Type A. 한글 읽기

문제:

아리가토

선택지:

- おはよう
- ありがとう
- おやすみ

### Type B. 한글 문자 선택

문제:

か に近い音のハングルを選んでください。

선택지:

- 카
- 나
- 마

### Type C. 문자 조합

문제:

ㄱ + ㅏ = ?

선택지:

- 가
- 나
- 고

### Type D. 새로운 단어 읽기

학습한 한글 자모로 구성된, 아직 배우지 않은 일본어 단어를 읽을 수 있는지 평가한다.

모든 퀴즈의 안내와 피드백은 일본어로 제공한다.

## 9. 데이터 모델

학습 콘텐츠는 UI 코드와 분리하여 관리한다.

다음은 JSON 데이터 구조의 예시이다.

```json
{
  "id": "consonant-001",
  "level": 1,
  "order": 1,
  "category": "basic_consonant",
  "targetJamo": "ㄱ",
  "targetSyllable": "가",
  "hangulJapanese": "가쿠세이",
  "kana": "がくせい",
  "japanese": "学生",
  "korean": "학생",
  "highlight": "가",
  "phoneticMatch": "approximate",
  "noteJa": ""
}
```

일본어 대응음이 없는 학습 항목은 null 값을 허용한다.

phoneticMatch는 발음 대응의 성격을 표시하기 위한 속성이다.

- approximate: 근사 대응
- none: 대응음 없음

향후 정밀한 발음 분석 및 표기 정책에 따라 확장할 수 있도록 설계한다.

## 10. 한글 커버리지 분석

향후 학습 데이터에 포함된 한글 문자를 자동 분석할 수 있도록 설계한다.

분석 대상:

- 초성 19개
- 중성 21개
- 종성 27개 형태
- 기본 자음 14개
- 기본 모음 10개
- 쌍자음 5개
- 복합 모음 11개

한글 일본어 데이터의 커버리지와 한국어 보충 데이터의 커버리지를 구분하여 측정한다.

일본어 일상 표현을 통해 최대한 많은 한글 문자를 학습할 수 있도록 콘텐츠 선정 및 정렬 알고리즘을 향후 개발한다.

## 11. 기술 스택 제안

기존 GitHub Repository의 코드 및 기술 환경을 먼저 확인한다.

기존 기술 스택이 있다면 최대한 유지한다.

빈 Repository라면 다음 구성을 기본으로 사용한다.

- React
- TypeScript
- Vite
- JSON 기반 학습 데이터
- CSS 기반 반응형 디자인
- LocalStorage 기반 학습 진행 상태 저장
- GitHub Pages 배포

초기 버전에서는 백엔드 서버, 회원가입, 데이터베이스, 유료 API를 사용하지 않는다.

가능한 한 단순한 구조로 시작한다.

Level 4~6의 전체 콘텐츠 구현은 후속 작업으로 진행한다.

## 15. MVP 완료 기준

다음 조건을 충족해야 한다.

1. 일본인 사용자가 일본어 UI를 통해 학습을 시작할 수 있다.
2. 기본 자음 14개가 지정된 순서로 표시된다.
3. 기본 모음 10개가 지정된 순서로 표시된다.
4. 각각의 문자에 연결된 학습 카드를 확인할 수 있다.
5. 자음과 모음을 선택하면 올바른 한글 음절이 생성된다.
6. 4가지 표현 체계가 지정된 순서로 표시된다.
7. 한글 읽기 퀴즈를 수행하고 결과를 확인할 수 있다.
8. 일본어에 없는 대응음을 잘못 생성하지 않는다.
9. 모바일과 PC에서 정상적으로 작동한다.
10. 빌드와 기본 테스트가 성공한다.

## 16. Codex 작업 지시

위 기획안을 기반으로 MVP Version 0.1을 개발한다.

먼저 현재 Repository 상태를 분석하고, 기존 코드가 있다면 이를 존중한다.

이 기획안을 docs/PROJECT.md에 정리하고, 학습 커리큘럼과 한글 표기 규칙을 별도 문서로 관리한다.

프로젝트 철학과 학습 순서를 임의로 변경하지 않는다.

구현 가능한 MVP 기능을 실제 코드로 작성하고, 테스트와 빌드를 실행한다.

작업 완료 후 다음 사항을 보고한다.

- 구현된 기능
- 생성 및 수정한 파일
- 주요 기술적 결정
- 테스트 및 빌드 결과
- 남은 문제점
- 후속 개발 제안

단순한 기획 문서 작성에서 끝내지 말고 실행 가능한 웹 애플리케이션을 구현한다.
