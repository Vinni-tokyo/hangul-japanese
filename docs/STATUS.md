# Hangul Japanese 작업 현황

마지막 갱신 · 2026-11-25 17:48 (Asia/Tokyo)

MVP v0.1의 학습 기능은 작업 트리에 구현되어 있다. 로컬 자동 테스트 11개와 프로덕션 빌드가 통과했다. 브라우저 동작과 GitHub Pages 배포 상태는 확인이 남아 있다.

## 완료한 작업

- [프로젝트 기획](PROJECT.md), [커리큘럼](CURRICULUM.md), [표기 규칙 초안](TRANSCRIPTION_RULES.md)과 로컬 실행 안내를 작성했다.
- 일본어 메인 화면, 기본 자음 14개·모음 10개 학습 카드, 자모 조합 140개를 구현했다. 가나 대응음이 등록된 음절에는 대응음을 표시한다.
- 가나를 고르는 한글 읽기 퀴즈, 주제별 일본어 일상 표현 30개, 학습한 카드와 퀴즈 최고 점수의 브라우저 저장을 구현했다.
- GitHub Pages용 GitHub Actions 워크플로를 작성했다. 워크플로에는 테스트, 프로덕션 빌드, 배포 단계가 있다.

## 진행 중인 작업

- MVP 검증 단계다. 자동 테스트와 빌드는 완료했고, 모바일·데스크톱 브라우저 점검과 GitHub Actions 실행 및 Pages 배포 확인이 남아 있다.

## 테스트 및 빌드 결과

Node.js v24.18.0, npm 11.16.0 환경에서 확인했다.

| 명령 또는 확인 항목 | 실제 결과 |
| --- | --- |
| `npm ci` | 작업 트리의 임시 사본에서 성공. 패키지 96개를 설치했다. |
| `npm test` | 저장소 루트에서 성공. Vitest 테스트 파일 1개, 테스트 11개 통과. 자모 순서와 140개 음절 조합, 가나 대응과 커리큘럼 데이터, 퀴즈 생성, 학습 진행 저장 로직을 검증했다. |
| `npm run build` | 저장소 루트에서 성공. TypeScript 검사와 Vite 프로덕션 빌드가 통과했고 `dist/index.html`과 JS·CSS 파일이 생성됐다. |
| 모바일·데스크톱 브라우저 | 미실행. |
| GitHub Actions 및 Pages 배포 | 원격 실행 및 배포 결과 미확인. |

## 막힌 점

- 첫 실행에서는 `vitest`와 `tsc`를 시작할 때 `Permission denied`가 발생했다. 저장소 루트에서 다시 실행한 결과 두 명령 모두 통과했다. 현재 로컬 테스트와 빌드를 막는 문제는 없다.

## 다음 작업

1. 모바일·데스크톱 브라우저에서 학습 카드, 자모 조합, 퀴즈 완료, 새로고침 후 진행 상태 복원을 확인한다.
2. 워크플로가 원격에 반영되면 GitHub Actions 결과와 Pages 공개 주소에서의 동작을 확인한다.
3. MVP 후속 범위로 Level 4~6의 쌍자음·복합 모음, 받침, 일본어 특수 소리 콘텐츠를 다룬다.

## Git 상태

- 로컬 `main`의 추적 기준 브랜치는 `origin/main`이다. 확인 당시 README는 수정 상태였으며, 앱 코드, 테스트, 문서, 배포 설정 등은 아직 Git에서 추적되지 않았다.

## 갱신 기준

- 공식 기획은 [PROJECT.md](PROJECT.md)에서 관리하고, 진행 상황은 이 문서에서 공유한다.
- 주요 작업 단계가 끝나거나 검증 결과·차단 사항이 바뀌면 갱신 시각(Asia/Tokyo), 완료한 작업, 진행 중인 작업, 실제 테스트·빌드 결과, 막힌 점, 다음 작업을 최신 상태로 갱신한다.
- 검증 결과에는 실제 실행한 명령과 결과를 기록한다. 실행하지 않은 점검은 미실행, 결과를 확인할 수 없는 점검은 미확인으로 표시한다.
